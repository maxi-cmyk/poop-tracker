# Frontend

Expo React Native app for PooPals.

## Structure

```text
app/          Expo Router routes and layouts
assets/       Fonts and static images
components/   Reusable UI components
constants/    Static constants
lib/          Client-side service and data helpers
types/        TypeScript domain types
```

## Commands

```bash
npm install
npm run start
npm run ios
npm run android
npm run web
```

Environment variables should be defined in `.env` in this directory. Use `.env.example` as the template.
